# database

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.2.19. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

Prisma
```bash
# generate client
bun prisma:generate

# push schema to database
bun prisma:db:push

# open studio
bun prisma:studio
```
