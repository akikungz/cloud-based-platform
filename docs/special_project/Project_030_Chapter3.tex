\hspace*{1.5em} %ย่อหน้า
ระบบแพลตฟอร์มคลัสเตอร์เสมือนได้รับการออกแบบในรูปแบบ Microservices Architecture โดยแบ่งเป็นส่วนประกอบหลัก 3 ส่วน คือ
\begin{mycustomitem}
    \item \textbf{Frontend} เว็บแอปพลิเคชันสำหรับผู้ใช้งาน พัฒนาด้วย Next.js และ React
    \item \textbf{Backend} เซิร์ฟเวอร์ API สำหรับการจัดการข้อมูลและการยืนยันตัวตน พัฒนาด้วย Elysia.js
    \item \textbf{Instance Management (VM Management)} เซอร์วิสจัดการเครื่องเสมือนและการสื่อสารกับ Proxmox VE
\end{mycustomitem}

\subsection{การออกแบบหน้าจอการทำงาน}
\hspace*{1.5em} %ย่อหน้า
การออกแบบหน้าจอการทำงานของระบบแพลตฟอร์มคลัสเตอร์เสมือนได้รับการออกแบบให้มีความสะดวกในการใช้งานและการเข้าถึงข้อมูลที่จำเป็น โดยแบ่งออกเป็นหน้าจอหลัก ๆ ดังนี้
\begin{mycustomitem}
    \item \textbf{หน้าจอเข้าสู่ระบบ (Login Page)} หน้าจอสำหรับผู้ใช้ในการเข้าสู่ระบบผ่านการยืนยันตัวตน
    \item \textbf{หน้าจอแดชบอร์ด (Dashboard)} แสดงภาพรวมสถานะเครื่องเสมือน รายการคำร้องขอ และข้อมูลผู้ใช้
    \item \textbf{หน้าจอจัดการเครื่องเสมือน (Instance Management)} สำหรับผู้ใช้ในการดูรายละเอียดเครื่องเสมือน เช่น สถานะ การเชื่อมต่อ และการจัดการเครื่อง
    \item \textbf{หน้าจอคำร้องขอเครื่องเสมือน (Instance Request)} สำหรับผู้ใช้ในการส่งคำร้องขอเครื่องเสมือนใหม่หรือขยายสเปกเครื่อง
    \item \textbf{หน้าจอจัดการคำร้องขอ (Request Management)} สำหรับเจ้าหน้าที่ในการตรวจสอบและอนุมัติคำร้องขอเครื่องเสมือน
\end{mycustomitem}

\subsection{การออกแบบฐานข้อมูล}

\hspace*{1.5em} %ย่อหน้า
ระบบใช้ PostgreSQL เป็นฐานข้อมูลหลัก โดยออกแบบตารางหลักดังนี้
\begin{mycustomitem}
    \item \textbf{User} เก็บข้อมูลผู้ใช้งาน การยืนยันตัวตน และความสัมพันธ์กับเซสชัน/บัญชี
    \item \textbf{Session} เก็บข้อมูลเซสชันการเข้าสู่ระบบของผู้ใช้
    \item \textbf{Account} เก็บข้อมูลบัญชีผู้ใช้จากผู้ให้บริการภายนอก (เช่น OAuth)
    \item \textbf{Verification} เก็บข้อมูลสำหรับการยืนยัน (เช่น โทเค็น/อีเมล)
    \item \textbf{staff\_list} รายชื่อบุคลากร/อาจารย์ที่ได้รับอนุญาต
    \item \textbf{user\_public\_key} คีย์สาธารณะของผู้ใช้ (เช่น SSH public key)
    \item \textbf{network} ข้อมูลเครือข่าย ชื่อเครือข่าย และเกตเวย์
    \item \textbf{ip\_address} รายการที่อยู่ IP และการผูกกับเครื่องเสมือน
    \item \textbf{semester} ข้อมูลภาคการศึกษา ช่วงเวลา และสถานะการใช้งาน
    \item \textbf{pve\_node} โหนดของ Proxmox VE และสถานะของโหนด
    \item \textbf{instance\_template} แม่แบบ VM/LXC และโหนดต้นทางที่ใช้สร้างเครื่อง
    \item \textbf{instance\_course} ข้อมูลรายวิชาและผู้รับผิดชอบสำหรับการจัดสรรเครื่อง
    \item \textbf{instance\_request} คำร้องขอเครื่องเสมือนของผู้ใช้ พร้อมสเปกที่ต้องการ
    \item \textbf{instance} เครื่องเสมือนที่ถูกจัดสรรให้ผู้ใช้ รวมสถานะการทำงานและโหนดที่รัน
    \item \textbf{instance\_request\_extends} คำร้องขอเพิ่มเติม/ขยายสำหรับเครื่องที่มีอยู่
\end{mycustomitem}

\hspace*{1.5em} %ย่อหน้า

    \item \textbf{Type Safety} รองรับ TypeScript แบบเต็มรูปแบบ
    \item \textbf{OpenAPI Integration} สร้าง API Documentation อัตโนมัติ
    % \item \textbf{Plugin Ecosystem} มี Plugin หลากหลายสำหรับการพัฒนา

\hspace*{1.5em} %ย่อหน้า

\begin{mycustomitem}
    \item \textbf{Type-safe Database Client} ป้องกันข้อผิดพลาดในการเขียน Query
    \item \textbf{Database Migrations} จัดการการเปลี่ยนแปลง Schema อย่างเป็นระบบ
    \item \textbf{Database Introspection} สร้าง Schema จากฐานข้อมูลที่มีอยู่

\subsection{Infrastructure และ DevOps}

\hspace*{1.5em} %ย่อหน้า
\textbf{Docker} ใช้สำหรับการ Containerization ของแอปพลิเคชัน เพื่อ
\begin{mycustomitem}
    \item \textbf{Environment Consistency} สภาพแวดล้อมการพัฒนาและ Production เหมือนกัน
    \item \textbf{Easy Deployment} ง่ายต่อการ Deploy และ Scale
    \item \textbf{Resource Isolation} แยกทรัพยากรระหว่างแอปพลิเคชัน
\end{mycustomitem}

\hspace*{1.5em} %ย่อหน้า
\textbf{Docker Compose} ใช้สำหรับการจัดการ Multi-container Application
\begin{mycustomitem}
    \item \textbf{Service Orchestration} จัดการการเริ่มต้นและหยุดทำงานของ Service
    \item \textbf{Network Management} จัดการเครือข่ายระหว่าง Container
    \item \textbf{Volume Management} จัดการการแชร์ข้อมูลระหว่าง Container
\end{mycustomitem}

\subsection{เครื่องมือการพัฒนา}

\hspace*{1.5em} %ย่อหน้า
\textbf{Version Control และ Collaboration}
\begin{mycustomitem}
    \item \textbf{Git} สำหรับการควบคุมเวอร์ชันของโค้ด
    \item \textbf{GitHub} สำหรับการเก็บโค้ดและการทำงานร่วมกัน

% 3.5.1
\subsection{วิธีการพัฒนา (Development Methodology)}

\hspace*{1.5em} %ย่อหน้า
โครงงานนี้ใช้วิธีการพัฒนาแบบ Agile Development โดยแบ่งการพัฒนาเป็น Sprint ขนาด 2 สัปดาห์ แต่ละ Sprint ประกอบด้วย
\begin{mycustomenum2}
    \item \textbf{Sprint Planning} วางแผนงานของ Sprint
    \item \textbf{Daily Standup} ติดตามความคืบหน้าและปัญหา  
    \item \textbf{Development} พัฒนาตาม User Stories
    \item \textbf{Testing} ทดสอบฟีเจอร์ที่พัฒนาเสร็จ
    \item \textbf{Sprint Review} ทบทวนผลงานและรับ Feedback
    \item \textbf{Sprint Retrospective} หาจุดปรับปรุงสำหรับ Sprint ถัดไป
\end{mycustomenum2}
